# CineHub 

|Live Demo|[Live Demo](https://cinehub-production-8631.up.railway.app/)|
|:----------|-----------:|
CineHub is a modern movie discovery web application built with React and Vite.

## Features
- Trending movies
- Smooth animations
- Responsive UI
- Dockerized deployment

## Tech Stack
- React
- Vite
- Tailwind CSS
- Docker
- Railway
